TWO PATHS. SEPARATE MEASUREMENTS.

Connection speed

EVERY 15 MINUTES

Tests run on the Pi. Home Internet uses its normal connection; Tor uses the gateway’s SOCKS connection, with no direct fallback.

Bounded single-request samples include connection overhead and may underestimate maximum line speed. HTTPS response time includes connection setup; it is not ICMP ping. Refresh data retrieves the latest saved results and does not start another test.

Measurement target: Cloudflare. Home samples use up to 4 MiB down + 1 MiB up; Tor samples use 256 KiB down + 64 KiB up. Failures are shown as unavailable, never zero speed.
